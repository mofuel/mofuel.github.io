Sobre mí

Soy mofuel, backend developer enfocado en construir APIs seguras, escalables y bien documentadas. Mi stack principal es Java con Spring Boot, con experiencia en autenticación JWT y diseño RESTful.

He trabajado en equipos donde yo cargo el backend y mis compañeros construyen el frontend — lo que me ha enseñado a diseñar APIs claras y contratos bien definidos entre capas.

También manejo Python para scripting, Docker para containerización, y tengo conocimientos básicos de frontend para entender el lado del consumidor.
